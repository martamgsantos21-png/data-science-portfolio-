# Healthcare Analytics — Technical Case Study

## Context and objectives

This academic Power BI project explores a synthetic hospital dataset in a simulated Massachusetts General Hospital reporting scenario. The objective was to build an accessible analytical report covering patient profiles, encounters, procedures, departmental activity, costs and readmissions.

## My contributions

**Relational modelling:** Organised the model linking encounter and procedure data to patients and supporting tables; created additional tables for reporting.

**Report development:** Designed a navigation experience and five analytical pages.

| Page | Focus |
| --- | --- |
| Patients | Patient demographics and geographical distribution |
| Encounters | Visit activity, trends, duration and costs |
| Procedures | Procedure activity, costs and insurance coverage |
| Readmissions | Readmission patterns and 30-day indicators |
| Departments | Departmental activity and patient distribution |

**User experience:** Configured report navigation, interactive filtering, custom tooltips and exploratory visualisations, including heatmaps, maps and a decomposition tree.

**KPI reporting:** Used measures supplied with the assignment to present operational indicators. **The original DAX measures were supplied by the instructor, not written by me.**

## Tools and skills demonstrated

Power BI · Relational data modelling · Report design · Interactive visualisation · Analytical communication

## Dataset and attribution

The course files included synthetic patient, encounter, procedure, organisation and payer data, a data dictionary, and a citation to Synthea:

Walonoski, J., et al. (2018). *Synthea: An approach, method, and software mechanism for generating synthetic patients and the synthetic electronic health care record.* Journal of the American Medical Informatics Association, 25(3), 230–238. https://doi.org/10.1093/jamia/ocx079

A related public dataset is [Hospital Patient Records — Maven Analytics](https://mavenanalytics.io/data-playground/hospital-patient-records).

This is an **academic case study**, not an official hospital dashboard or a report based on real patient records. The course provided a starter PBIX and existing measures; this portfolio highlights my modelling, dashboard design and visual reporting contributions.
