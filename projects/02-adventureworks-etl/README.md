# AdventureWorks | Data Preparation & ETL

**Academic project · Power Query · Data transformation · Data modelling**

## Overview
A data preparation and modelling project using AdventureWorks data. The workflow focused on cleaning and restructuring source information for downstream analysis.

## Technical focus
- Data cleaning and standardisation using Power Query.
- Extraction and reconstruction of product attributes from inconsistent text fields.
- Table joins and preparation of fact and dimension tables.
- Transformation logic to support a structured analytical model.

**Tools:** Power BI, Power Query (M), ETL, relational data modelling.
