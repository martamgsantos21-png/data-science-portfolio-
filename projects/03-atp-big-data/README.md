# ATP Tennis | Big Data Management & SQL

**Academic group project · Database design · SQL transformations · Analytical queries**

## Overview
Worked with a historical professional tennis dataset to develop a structured relational database and support analytical queries. The workflow involved preparing source data, normalising identifiers and dates, designing linked tables and validating relationships.

## Technical workflow
1. Explored and prepared source records, including handling missing or inconsistent values.
2. Standardised date formats and country representations.
3. Generated consistent identifiers for players and tournaments, taking into account players with the same name.
4. Structured data into related **Player**, **Tournament**, **Matches** and **Countries** tables.
5. Applied primary/foreign keys and indexes to support data integrity and querying.
6. Investigated duplicated match representations and wrote SQL queries to explore performance by player, country, tournament and court surface.

**MySQL · SQL · MongoDB · Docker · phpMyAdmin · Data cleaning · Relational modelling · Window functions · Analytical querying**
