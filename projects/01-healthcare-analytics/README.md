# Healthcare Analytics | Power BI

**Academic project · Business intelligence · Data modelling · Interactive dashboards**

Built a Power BI reporting experience for synthetic hospital records, exploring patients, encounters, procedures, departments, costs and 30-day readmissions.

**My work:** relational data modelling, supporting tables, dashboard design, navigation, interactive filters and visual storytelling. The original DAX measures were supplied by the instructor.

**Tools:** Power BI, relational modelling, data visualisation.
